# K-13 Rodičovské centrum

## Účel
Umožňuje rodičovi zobraziť schválené informácie o vlastnom dieťati na základe väzby rodič-dieťa.

## Dáta
- Reuse existujúcej väzby `identity_guardian_link` (GuardianLink). Modul nevytvára nové DB tabuľky.

## API a udalosti
- Registrácia routera: `/parent` (`k13-parent`).
- Bez doménových event subscriptions v aktuálnom rozsahu.

## Pravidlá prístupu a audit
- Rodič (`GUARDIAN_OF`) vidí iba údaje vlastného dieťaťa v rámci školy.
- Prístup iných rolí alebo k nezačlenenému dieťaťu je zamietnutý (deny-by-default).
- Poznámky učiteľa označené ako súkromné (`TEACHER_PRIVATE_NOTE`) sa rodičovi nikdy nezobrazujú; prehľad vracia len schválené informácie (bez súkromných poznámok).
- Akcie čítania sú auditované.

## Testy
- `backend/app/modules/k13_parent_center/tests/test_service.py` - rodič vidí vlastné dieťa, nezačlenené dieťa/iné roly zamietnuté, súkromné poznámky nezverejnené.
