# K-07 Profesijna kniznica

## Ucel
Knižnica pracovných materiálov učiteľa (prípravy, zdroje) s verziami, štítkami a archiváciou, ktorá prežíva zmenu školského roka. Súbory sú ukladané cez rozhranie FileStorage (lokálna implementácia).

## Entity (tabulky, oblast teacher_workspace)
- `teacher_workspace_library_item`: položka vlastnená učiteľom (`owner_teacher_user_id`), názov, popis, `archived`, platnosť/verzia, `is_demo`.
- `teacher_workspace_library_version`: verzia položky (`version_number`, `storage_key` pre súbor, `content_text`, poznámka).
- `teacher_workspace_library_tag`: štítok položky.

## Udalosti
- Registrácia handlerov cez `events/handlers.register(bus)` (zatiaľ bez odberu).

## Opravnenia
- Prístup iba vlastník (učiteľ, scope SELF) alebo system interne; ostatní zamietnutí (deny by default). Všetky operácie audituje `core/audit`.

## Rozhranie (API)
- `GET /k07/status` - stav modulu.

## Úložisko súborov
- Rozhranie `FileStorage` (`backend/app/shared/storage.py`) s lokálnou implementáciou `LocalFileStorage` (adresár mimo gitu, napr. `.data/storage`). Verzie môžu odkazovať na `storage_key`.
